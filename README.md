# Aplikasi Kos-Kosan

Aplikasi web untuk mengelola kos-kosan dengan fitur seperti dashboard, kamar, penghuni, pembayaran, dan laporan.

## Fitur Utama

- Dashboard ringkas statistik kos-kosan
- Manajemen kamar
- Manajemen penghuni
- Manajemen pembayaran
- Laporan bulanan

## Tech Stack

- React 18 + Vite
- Tailwind CSS
- React Router
- Lucide React

## Instalasi

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
